skylakegrep 0.7.5 — Native MCP MVP + stdio framing

0.7.5 ships the native MCP server to PyPI and fixes Content-Length framing for Cursor / Claude Code pipes.

What changed

  • Native MCP MVP (#22). skygrep mcp / skygrep-mcp expose tools search and agent_context over JSON-RPC stdio (same retrieval contract as CLI --agent-context for the latter). See docs/mcp.md.
  • Binary stdio framing (#23). Read/write via stdin.buffer / stdout.buffer so Content-Length matches raw pipe clients.

Compatibility

  • Still Python 3.9+; the official mcp SDK is not a package dependency.
  • Apache-2.0, offline-first. Existing indexes untouched.
  • Cursor verified end-to-end; other MCP clients: same protocol, configure and verify separately.

Positioning

Apache-2.0 · offline · CLI / agent_context harness · MCP MVP usable — not a do-everything production agent platform.
