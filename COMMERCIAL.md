# Commercial use, support, and enterprise

**The short version: skylakegrep is Apache-2.0. You can use it
commercially, inside a company, inside a paid product, on client
machines, at any scale, for free. No license to buy, no seat count, no
call with sales.**

That is deliberate. A local-first retrieval tool is only useful if it can
be installed everywhere, including inside agent harnesses and corporate
laptops whose legal review rejects copyleft and noncommercial terms.

What you owe in exchange is small and non-negotiable:

- keep the `NOTICE` attribution when you redistribute or embed it
  (Apache-2.0 §4(d))
- rename your fork if you modify and redistribute it
  (see [`TRADEMARK.md`](TRADEMARK.md))
- cite it in published work (see [`CITATION.cff`](CITATION.cff), or run
  `skygrep cite`)

## What is sold

The open core stays open. These are the things that are not in it:

**Team index server (shared, on-premises).** A multi-user index server
with SSO, per-directory access policy, audit logging, and an admin
surface. On-premises — still no cloud, still no file contents leaving
your network. Proprietary, licensed per organisation.

**Priority support with an SLA.** Named contact, response-time
commitment, private issue triage, backports onto a version line you have
pinned.

**Integration and deployment work.** Custom extractors for internal file
formats, embedding-model selection and calibration against your own
corpus, agent-harness integration, benchmark harness adapted to your
data with committed receipts.

**Indemnification and compliance paperwork.** SBOM, license attestation,
supplier forms, security questionnaire responses.

## Why the core is free and these are not

Everything above requires work per customer, or carries per-customer
liability. The tool itself does not. Charging for the tool would buy the
project nothing except invisibility — which is what the previous
noncommercial license bought it.
